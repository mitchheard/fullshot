Three ways to capture

Pick the output. Skip the rest.

Every mode captures the full page height. Each has its own shortcut, and you can remap them in Chrome.

PDF

A tiled PDF with an invisible text layer, so you can search it, select from it, and hand it to anything that reads text.

⌘⇧S/AltShiftS

Image

A PNG or JPEG saved to your Downloads, and a PNG copied to your clipboard at the same time. Optionally saves tiles too.

⌘⇧I/AltShiftI

Copy

Straight to the clipboard and nothing written to disk. Paste it into a chat, a doc, or a ticket and move on.

⌘⇧Y/AltShiftC

Built for pages that fight back

Dashboards, chat apps, endless articles.

Plenty of screenshot tools stop at the first viewport. fullshot is built around the pages that break them.

01

Scrolling panels, handled

When an inner pane scrolls instead of the page, as in dashboards and chat UIs, fullshot temporarily unclips it for the capture, then restores it exactly.

02

Very tall pages

Pages are captured in segments and stitched together, so length isn't limited by what a single screenshot call allows.

03

Lazy-loaded content

It scrolls through the page first to wake lazy images and sections, then returns you to where you were before capturing.

04

No doubled headers

Sticky and fixed elements are captured once at their natural position, not repeated at every scroll step.

Two kinds of PDF

Pixel-exact, or vector-sharp.

Choose once in options. Both are searchable, and both work from the same shortcut.

Default

Claude PDF

The page is sliced into tall tiles, one per PDF page, each with an invisible text layer on top.

  • Pixel-exact: it looks like the live page, including canvas and WebGL content
  • Searchable and selectable text layer
  • Tile edges can split a paragraph across two pages
Experimental

Vector PDF

Chrome's own print-to-PDF at full page size, as one continuous page with real vector text.

  • No tile seams, and usually a smaller file
  • Crisp at any zoom level
  • Depends on Chrome's print rendering, which can differ on canvas-heavy pages

Privacy, by construction

Nothing leaves your machine.

No accounts, no analytics, no servers. The extension makes no network requests, the PDF library is bundled rather than loaded from a CDN, and it declares no host permissions, so it can't read the sites you visit. Every permission it does ask for is below, and why.

PermissionWhy it's needed
debuggerDrives Chrome's DevTools Protocol for the screenshot, scrolling and print-to-PDF.
activeTabReads the current tab's URL and title for filenames, only when you invoke it.
downloadsSaves the finished file to your Downloads folder.
clipboardWritePuts the image on your clipboard.
offscreenCreates the temporary file URL a download needs.
storageRemembers your options on this device.

Get it running

Three steps, about a minute.

fullshot is loaded as an unpacked extension for now. It isn't on the Chrome Web Store.

  1. Step 01

    Download

    Grab the ZIP from GitHub and unzip it, or clone the repo. You'll get a fullshot folder.

  2. Extensions Developer mode
    Load unpacked Pack extension
    Step 02

    Load unpacked

    Open chrome://extensions, switch on Developer mode, click Load unpacked, and pick the folder.

  3. ⌘ ⇧ S
    Step 03

    Capture

    Pin the icon, then press ⌘⇧S on any page. On Windows and Linux it's AltShiftS.

Straight answers

Good questions.

Why does Chrome say "fullshot started debugging this browser"?

fullshot uses Chrome's debugging protocol to take the screenshot, and Chrome always shows that bar while an extension is attached. It can't be hidden, and fullshot detaches the moment the capture finishes.

Why isn't it on the Chrome Web Store?

The debugger permission shows a strong install warning and gets extra review there, so for now it's distributed as source. You can read every line of it before you load it.

Does it work on every page?

Almost. Chrome blocks extensions on chrome:// pages and the Web Store. Virtualized lists, where rows don't exist until you scroll to them, can only be captured as far as they've rendered. Fixed UI like a chat composer can land mid-page in app-style layouts.

Nothing happened when I pressed the shortcut.

Check chrome://extensions/shortcuts. Chrome sometimes keeps a previously assigned key instead of the default. The options page lists whatever is actually bound right now.

Is it free?

Yes. It's MIT licensed, with no accounts, no tiers and no tracking.
